[English](README.md) | **日本語**

- Show Tracks は、ショーの本番向けに開発した再生専用の Web アプリです。1 ページで扱えるのは、オーディオファイル 1 つと映像ファイル 1 つだけです。編集機能はついていません。できるのは、トラックの最初と最後のポイントを指定することだけです。
- トラックに打ったマーカーのタイミングで、文字を出力できます。音楽に合わせて歌詞を表示したり、演者へのカンペを出したり、文字を映像の上に載せてカラオケビデオ風にしたりできます。
- **DAW に合わせて文字を出せます**: DAW から来る MTC に合わせて動くこともできます。音は DAW が出し、Show Tracks は歌詞やカンペ、字幕をタイミングどおりに表示します。MTC を送れる DAW なら何でも使え、ブラウザだけで無料で動きます。
- 同じようにマーカーのタイミングで MIDI Note を出力できます。外部機器の制御用です。
- ページ管理で曲順を決めます。曲が終わったら次のページを自動で再生したり、オーバーラップ機能で曲の終わりに重ねて次の曲を始めたりできます。
- 再生時間で MTC を出力します。照明や DAW を合わせて動かせます。
- Chrome 専用です。メディアとプロジェクトは、このブラウザの中に保存されます。

> [!IMPORTANT]
> **PC の Chrome 専用です。** スマートフォンやタブレットでは動きません。キーボード、別ウィンドウの出力画面、Web MIDI や File System Access API などの Chrome の機能を使っています。

**アプリを開く: https://hugesesame.github.io/show-tracks/**

> 本番で使う前に、お手持ちの機材で一度通して動かしてください。[本番の前に](#本番の前に)を参照してください。

## できること

- **ページで曲順を決めます。** 1 ページに入れられるのは、オーディオファイル 1 つと映像ファイル 1 つです。ページの終わりで、止まる / 次のページを開く / 次のページを再生する、を選べます。
- **ドラッグ＆ドロップ**: 音声や映像のファイルを画面にドロップできます。1 つなら開いているページに入り、複数ならファイル名のページが順に 1 つずつできます。プロジェクトファイルは Import と同じように開きます。
- **本番は Space、リハーサルは G。** 本番では、ページが終わると次のページが待機に入り、良いタイミングで `Space` を押して始めます。リハーサルでは、**GO**（`G` キー）で Cue から再生し、曲のどこへでもすぐに戻れます。
- **Cue** はトラックに打つマーカーです。GO のボタンに、次に再生する待機中の Cue が出ます。**Cue List** で選び直せます。
- **イン点とアウト点**で、曲の一部だけを再生できます。
- **オーバーラップ**: 曲の終わりにマークを置くと、そこで次のページが始まり、前の曲の終わりは下で鳴り続けます。映像も同じ時間をかけて（マークから前の曲のアウト点まで）次のページの映像へディゾルブします。カラオケのような見せ方ができます。ディゾルブの間はそれぞれの画面で映像を 2 本同時に再生します。フル HD ならたいていの PC で問題ありませんが、4K の映像はコマ落ちすることがあります。
- **Cue のタイミングで文字を表示**: 音楽に合わせた歌詞、演者へのカンペ、映像の上に文字を載せたカラオケ風の映像などに使えます。文字のサイズ、色、縁、位置、切り替わりのディゾルブを選べます。
- **表計算ソフトから歌詞を読み込む**: Cue List の **CSV ▾** で、Time、Name、Memo の列からメモを読み込めます。Time がなければ Cue に上から順に入り、Time があればその時間の Cue に入ります。セルの中の改行は、メモでも改行になります。Export で書き出して編集することもできます。Export SRT では、メモを字幕ファイル（時間はページの頭から）として書き出せるので、本番の録画に動画編集ソフトで字幕を入れるときに使えます。サンプル: [順に入れる](public/samples/memos-in-order.csv)、[時間付き](public/samples/cues-with-times.csv)。
- **Cue のタイミングで MIDI Note を送信**: 照明などの外部機器の制御用です。Cue ごと、またはページごとにまとめて On / Off できます。
- **MTC** は再生時間に合わせて出力します。ページごとにオフセットを付けられます。
- **DAW に合わせる**: PAGES には Play と MTC In の 2 つの一覧があります。MTC In のページは、Cue を打てる空のトラックです。DAW から来る MTC に合わせて再生・停止・移動し、メモと MIDI Note をタイミングどおりに出します。音は DAW が出します。
- **MIDI リモート**: フットスイッチ、パッド、卓のボタンで、GO、Play / Stop、Fade out、Duck、前 / 次の Cue を操作できます。Learn を押してからキーを押すだけで割り当てられます。
- **映像出力ウィンドウ**を 2 台目のディスプレイに出せます。文字は映像の上に重なります。
- **プロンプター**: 文字だけを出す演者用のウィンドウです。映像出力の文字を Off にすれば、お客さんには映像だけ、演者には歌詞やカンペだけを見せられます。手元の画面も同じ比率で表示するので、お客さんが見ている画面と同じものを確認できます。
- **ミキサー**: Audio、Video、Master のフェーダー、Pan、ミュート。MIDI のフェーダー機材（CC または Pitch Bend / Mackie Control）でフェーダーを動かせます。機材のフェーダーが画面の音量まで来たところでつながるので、音が跳ねません。
- **ダック**（`D`）: アナウンスのときに全体の音を下げ、もう一度押すと戻します。下げる量と時間は設定で変えられます。
- **音の出力先**: オーディオインターフェースなど、好きな機材から音を出せます。本番中に機材が抜けても、その間は PC の標準の出力から鳴り、つなぎ直すと元の機材に戻ります。
- **ショーモード**で、本番中は編集をロックできます。誤ってクリックしても、Cue や再生位置が動きません。
- **ヘルプ**は英語と日本語でアプリの中にあります。`?` キーで開きます。

## 使い始める

1. PC の Chrome でアプリを開きます。
2. 最初のページで、Audio（映像があれば Video も）の **Choose** を押してファイルを選びます。WAV、MP3、M4A、MP4 など、Chrome で再生できる形式なら使えます。
3. `Space` で再生し、Cue を打ちたいところで `M` を押します。ページは PAGES の **+** で増やします。
4. 歌詞やカンペを入れるには、Cue List を **Memo** に切り替えて、Cue をダブルクリックして入力します。`Shift+Enter` で改行します。
5. **Open Video Output** を押して、出てきたウィンドウを 2 台目のディスプレイに移します。ダブルクリックか `F` キーで全画面になります。
6. MTC と MIDI Note を使うときは、**Settings**（`⌘,`）で MIDI の出力先を選びます。

操作とキーボードショートカットの一覧は、`?` キーか、PAGES の一番下の **Help** で見られます。

### ブラウザから聞かれること

最初に使うときに、ブラウザから許可を求められます。**許可**を選んでください。間違えてブロックしたときは、アドレスバーの左のアイコンを押して設定を変えます。

| いつ | ブラウザから聞かれること | 理由 |
|---|---|---|
| アプリを開いたとき | MIDI デバイスの制御 | MTC と MIDI Note を送り、MIDI リモートと DAW からの MTC を受け取るため |
| **Open Video Output** を押したとき | ポップアップの許可（ウィンドウがブロックされたときだけ） | 出力ウィンドウを開くため |
| 初めて **Save** を押したとき | ファイルの保存先 | プロジェクトファイルを書き込むため |
| Audio Output の横の **Show Names** を押したとき | マイクの使用 | Chrome はこのときだけ出力機材の名前を教えるため。録音はしません |
| **Backup**、**Restore**、**Find Media** を押したとき | フォルダの場所と、その中のファイルを見る（書き込む）許可 | バックアップとメディアを書き出す・読み込むため |

Mac では、Audio MIDI 設定の **IAC ドライバ**で、同じ PC のほかのアプリに MIDI を送れます。

## ショーの保存場所

- ショーと、その音声・映像は、作業しながらこの PC のブラウザの中に自動で保存されます。
- どこにも送信されません。ほかの PC や、同じ PC のほかのブラウザにはありません。
- ブラウザのサイトデータを消すと、ショーとメディアも消えます。
- アプリを 2 つ以上のタブで開くと、黄色い警告が出ます。タブ同士で編集を上書きし合うので、1 つ以外は閉じてください。
- **Save**（`⌘S`）で、好きな場所にプロジェクトをファイルとして保存できます。**プロジェクトファイルに音声や映像は入りません。**
- **Backup**（**Settings** の中）で、プロジェクトとすべての音声・映像をフォルダに書き出せます。ほかの PC に移すときはそのフォルダをコピーし、移した先で **Restore** で開きます。本番の前には毎回取っておいてください。
- **Find Media**（**Settings** の中）: プロジェクトファイルしかないときは、元の音声・映像ファイルがあるフォルダを選ぶと、見つからないメディアをファイル名で探して割り当てます。

## インターネットがない場所で

- アプリを開いたあとは、接続が切れても動き続けます。再生、MTC、MIDI、出力ウィンドウはインターネットを使いません。
- アプリは自分のコピーをブラウザの中に保存します。右下に **Offline Ready** と出ていれば、その PC では接続がなくても、アプリを開き直したり再読み込みしたりできます。出力ウィンドウも使えます。
- 接続のない会場に PC を持っていく前に、接続のある場所で一度アプリを開いて、**Offline Ready** が出ることを確かめてください。
- 接続があるときは、開くたびに最新版を読み込みます。

## 本番の前に

- 本番で使う PC で、一度最初から最後まで通して動かしてください。音声、映像、出力ウィンドウ、MIDI 機材も確かめます。
- Chrome は自動で更新され、まれに更新で動きが変わることがあります。アプリも、接続があるときは最新版を読み込みます。本番の直前には Chrome を更新しないでください。更新されたときや、アプリが新しくなったときは、もう一度通して確かめてください。
- 音声・映像も入った **Backup** を取っておきます。
- 接続のない会場では、**Offline Ready** が出ていることを確かめます（上の節を参照）。

## 自分の PC で動かす

ここは、アプリを改造したり自分でビルドしたりしたい人向けです。使うだけなら必要ありません。上のリンクを開いてください。Node.js 20.19 以降または 22.12 以降が必要です。

```bash
npm install
npm run dev
```

ターミナルに出たアドレス（ふつうは http://localhost:5173/）を開きます。

| コマンド | 内容 |
|---|---|
| `npm run dev` | 開発用サーバーを起動します。コードの変更がすぐに反映されます |
| `npm run build` | 型チェックをして、アプリを 1 つのファイル `dist/index.html` にビルドします |
| `npm run preview` | ビルドしたアプリを `dist/` から手元で開きます |
| `npm test` | テストを実行します |

公開サイトと手元の環境では、保存されたショーは別々です。行き来するときは **Save** と **Import** を使ってください。

| 場所 | 中身 |
|---|---|
| `src/app/` | アプリの状態と操作 |
| `src/engine/` | 再生、2 台のオーディオデッキ、ミキサー、MTC と MIDI の出力 |
| `src/cue/` | GO と待機中の Cue |
| `src/model/` | ページ、Cue、イン点 / アウト点、オーバーラップ、メモ |
| `src/media/` | 音声・映像ファイルの読み込みと波形 |
| `src/ui/` | メイン画面: トラック、ページ、Cue List、ミキサー、Memo 画面、設定、ヘルプ |
| `src/output/` | 映像出力ウィンドウ |
| `src/storage/` | ブラウザへの保存とプロジェクトファイル |
| `tests/` | テスト |

TypeScript と Vite で作っています。UI フレームワークは使っていません。
